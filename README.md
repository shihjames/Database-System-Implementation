# Database-System-Implementation

## Author: James Shih

This project provides a hands-on, in-depth exploration of database system internals.

* Buffer and File Management: Implemented efficient algorithms for managing data storage and retrieval, critical for optimizing database performance.
* Record Manager: Designed and built a record manager to organize and access individual data records within the database, a fundamental component of DBMS architecture.
* Sorted File Implementation: Created a sorted file structure for efficient data searching and retrieval, leveraging advanced algorithms and data structures.
* B+-tree Implementation: Implemented a B+-tree index, a sophisticated data structure crucial for fast data access in large databases.
* SQL Type Checking: Developed type checking mechanisms for SQL queries, ensuring data integrity and preventing errors.
* Relational Operators: Implemented relational algebra operators (select, project, join, etc.), the core operations for querying and manipulating data in a relational database.
* Optimization: Designed and implemented query optimization techniques to improve the efficiency of database queries, a critical challenge in large-scale data processing.
* Putting it All Together: Integrated the various components into a functional database system, demonstrating a comprehensive understanding of DBMS architecture and implementation.
